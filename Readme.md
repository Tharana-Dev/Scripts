# 🐧 Linux & Automation Scripts

A curated collection of Bash scripts for system administration, automation, and workflow optimization. Built from scratch as part of my self-taught Linux journey.

## 📂 Script Directory

| Script | Description | Stack |
| :--- | :--- | :--- |
| 📦 **[Portfolio Organizer](./portfolio_organizer)** | Creates clean, lightweight backups of development directories. Automatically excludes `venv`, `__pycache__`, and `.git`, compresses to `.zip`, and generates a detailed backup report. | `Bash` `Zip` `Coreutils` |

*(More scripts coming soon...)*

## 🚀 How to Use This Repository

Each script is contained within its own folder and includes its own dedicated `README.md` with specific instructions.

1. Clone the repository:
   ```bash
   git clone https://github.com/Tharana-Dev/Scripts.git
   cd Scripts
   ```

2. Navigate to the script you want to use:
   ```bash
   cd portfolio_organizer
   ```

3. Make the script executable and run it:
   ```bash
   chmod +x log.sh
   ./log.sh
   ```
